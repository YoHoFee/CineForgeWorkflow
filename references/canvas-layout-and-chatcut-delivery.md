# Canvas 排布、导出与 ChatCut 交付

本契约把已验收的 Canvas 工作区组织成可追踪、可继续剪辑的素材交付。它不替代当前
Canvas 工具、ChatCut connector 或 Drama Skills 的实时 schema；每次操作仍需读取当前
画布与工具状态。

## Canvas 片段排布

- 先读取实时画布及相关节点，锁定当前 `projectId/clientId`；不得仅凭浏览器标签、旧聊天
  或节点坐标推断当前连接。
- 片段编号从上到下递增。
- 每个候选视频单元内提示词在左、视频在右；同一片段的不同候选从左到右并排。
- 片段已确认版本放在本片段最左侧；候选节点标题包含片段编号和版本/状态，例如
  `SEG-008｜已确认｜v2`。新生成节点沿用相同命名和结构。
- 视频列保持紧凑，按约 2 个画布网格单位留距。位置整理后复读状态，确认只移动了目标
  节点、没有改写连线或媒体关系。
- 清理失败或重复节点前核实任务 ID、媒体状态和采用关系。只删除确定无用且授权删除的
  节点；不能仅因失败标签或重复标题删除可能已在供应商成功的结果。

## 生成回填故障

供应商成功、Canvas 解析/下载/回填失败是不同阶段。图片或视频即使在 Canvas 显示
`error`、`loading` 或没有预览，也可能已在供应商端生成。

1. 查当前 config、任务 ID 和 `generation_get_status`；如有任务 ID，查询原任务及供应商
   终态，确认是否已产生媒体。
2. 原任务成功时优先恢复、解析或回填现存结果；检查媒体证据后再决定下一步，不重复
   提交同一请求。
3. 只有确认没有被接受的任务，或原任务已明确失败且可重试，才发起一次新任务。检查
   同片段是否已有 `loading/queued/running/videoTaskId`，避免一次生成误产生两段候选。
4. 回填成功标准是节点含可读取真实媒体及正确 MIME/尺寸，不只是状态、URL 字符串、
   文件名或 metadata。图片/视频的具体 API 响应恢复规则遵循
   [问题指引](problem-guide.md)，不能把某个供应商响应结构推广到其他渠道。

## 导出与精确映射

随机下载文件名、画布顺序和坐标都不是媒体身份。导出必须使用可核验的键一一映射：

1. 从实时 Canvas 读取每个采用片段的编号、所选版本、节点 ID，以及该节点真实媒体的
   `storageKey`（或当前导出 API 提供的等价稳定媒体键）。
2. 使用当前可用的 Canvas MCP 导出工具、本地导出接口或可控的浏览器下载流程导出素材。
   本地部署按本地服务/工具契约处理；若用户表示画布视图、平移或缩放已改变，先重新
   读取实时节点，不要因旧 viewport 或坐标失配放弃导出，也不要让用户手动逐个导出/改名。
3. 用节点 ID 和媒体存储键精确匹配导出包条目；每个采用节点必须恰好匹配一个媒体文件，
   每个目标文件也只能对应一个节点。不能通过近似标题、时间顺序、文件大小或随机 UUID
   猜测。
4. 导出后复制/整理为稳定名称，例如
   `MOTION-<EP>-SEG-008__<canvasNodeId>.mp4`；名称只为可读性，清单中的稳定映射键才是
   权威关联。
5. 每集在 `制作成果/media-manifest.json` 记录片段 ID/标题、Canvas 节点 ID/标题、媒体
   存储键、文件名、相对路径、MIME、字节数、SHA-256、宽高、时长、模型，以及未采用/
   跳过原因。
6. 校验文件真实存在、节点与文件一对一、SHA-256/大小匹配，并抽查媒体流的画幅、帧率、
   时长和音频轨。缺失、重复或不一致时停止交付并修复映射，不猜测补齐。

## ChatCut 剪辑交接

- 用户要求逐集完成成片时，最终采用的视频素材应全部按 manifest 映射并导入同一个目标
  ChatCut 项目；先加载 ChatCut 基础与导入/剪辑对应 Skill，使用当前可用的 connector
  导入流程，不要求用户手动逐个传素材。
- 根据该集剪辑单按序排入 ChatCut 时间线，记录片段顺序、入出点、采用/跳过状态、声音、
  字幕和输出规格。以可编辑素材与时间线构成为交付主体，不用本地压平视频替代剪辑工程。
- 导入成功、时间线编排、时间线检查、最终渲染是不同状态。只有真实检查了相应阶段，才
  能分别报告“已导入”“已编排”“已核验”或“已导出成片”；不能把素材导入描述成最终
  成片完成。
- 导出前后核验片头、片尾、切点、总时长、音轨、字幕和目标格式；将导出路径、规格、
  时长、响度及尚未检查的项目记入该集剪辑单/交付记录。
- 默认声音方案是对白/人声与叙事音效，不加背景音乐；仅在创作者明确授权该集 BGM 时
  添加，优先在 ChatCut 后期统一配乐。
