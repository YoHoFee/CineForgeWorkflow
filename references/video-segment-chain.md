# 视频片段链交接契约

本契约属于 `$short-video-workflow` 编排层，用于处理目标时长超过视频模型单次生成
上限的连续视频。它不修改第三方视频模型 Skill，也不把多个独立片段伪装成一个任务。

## 模型上限

默认使用项目 `production_profile` 中的目标模型能力档案。已知默认上限如下：

| 模型 | 单次最长时长 |
| --- | ---: |
| `minimax-h3` / H3 | 15 秒 |
| `seedance-2.0` | 30 秒 |
| `seedance-2.5` | 30 秒 |

如果项目能力档案提供了更严格的上限，以项目档案为准。不能只把超长秒数写进提示词，
再让下游 adapter 自行截断。

## 拆分规则

1. 先确定本镜或本段的目标总时长和目标模型上限。
2. 若总时长不超过上限，使用一个片段。
3. 若总时长超过上限，按模型上限拆成多个片段；例如：
   - H3 的 35 秒：15 秒 + 15 秒 + 5 秒。
   - Seedance 的 45 秒：30 秒 + 15 秒。
4. 优先在分镜已经存在的自然动作落点、状态落点或镜头边界拆分。
5. 如果单个分镜内部超过模型上限，必须重新规划为连续片段，不能把中间动作
   静默截断，也不能把片段 2 重新当作文生视频。
6. 每个片段的时长必须落在目标模型支持范围内，所有片段时长总和必须等于目标总时长。

## 首尾帧接力

连续片段必须形成单向链：

```text
原始首帧
  → 片段 1
  → 片段 1 的真实视频尾帧
  → 片段 2
  → 片段 2 的真实视频尾帧
  → 片段 3
  → ...
```

具体规则：

- 片段 1 使用原始冻结关键帧或本镜声明的真实起始参考。
- 片段 2 及之后必须使用上一片段生成结果中提取的**真实尾帧**作为首帧参考。
- 真实尾帧必须建立为可读取的项目媒体或 Canvas 图片节点，并记录节点 ID、尺寸、
  画幅和来源视频 ID。
- 不能用文字描述、计划中的关键帧、上一片段的提示词或截图占位来冒充真实尾帧。
- 后续片段可以继续绑定角色设定图、场景图等稳定参考，但上一片段真实尾帧负责
  当前可见起始状态。
- 同一链必须串行生成。上一片段没有通过视频验收并提取尾帧时，不得提交下一片段。
- 任何片段参数、参考集合、模型、时长或起始尾帧发生变化，都必须使后续片段和
  原确认一起失效，重新建立片段链。

## 片段记录

每个片段至少记录：

```json
{
  "segmentId": "SEG-001",
  "sourceShotId": "MOTION-001",
  "index": 1,
  "durationSeconds": 15,
  "startFrameSource": "frozen-keyframe",
  "startFrameRef": "keyframe-001",
  "outputVideoRef": null,
  "tailFrameRef": null,
  "status": "planned"
}
```

片段 2 的最小记录必须体现：

```json
{
  "index": 2,
  "startFrameSource": "actual-tail-frame",
  "startFrameRef": "tail-SEG-001",
  "previousSegmentId": "SEG-001"
}
```

允许的片段状态为：

```text
planned
awaiting_previous_output
ready
in_production
generated
tail_frame_extracted
blocked
completed
```

## 生产与拼接

- 片段 1 生成并验收后，提取真实尾帧，再解锁片段 2。
- 片段 2 及之后只在前一片段拥有真实视频和真实尾帧时提交。
- 所有片段完成后，交给 `$short-drama-edit` 按片段索引拼接。
- 拼接阶段要检查画幅、帧率、音频连续性、尾首画面重复帧和总时长。
- 片段链未完成时，不能把已完成的第一片段登记为整段最终成片。
