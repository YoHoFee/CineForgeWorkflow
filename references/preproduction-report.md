# 合并制作设计报告

每个新任务都必须在任何付费生产前生成一份报告。该报告是本任务唯一的确认依据。

## 必备章节

1. **任务契约**：标题、格式、时长、画幅、平台、音频和排除项。
2. **创作方向**：前提、基调、视觉风格、结尾和风险说明。
3. **故事包**：人物关系、场次顺序、剧本、镜头表和时间安排。
4. **资产决策**：逐个角色和场景标记 `reuse`、`generate` 或 `variant`，并记录
   已保存资产 ID 或计划使用的节点。
5. **角色设定图**：每个新角色一张 16:9 统一角色设定图，遵循四区模板。
6. **场景设定图**：每个新场景一张无人物 16:9 场景设定图，遵循多角度分区模板。
7. **提示词与参考图**：完整的图片/视频提示词及有序参考图绑定关系。
8. **生产参数**：模型、图片质量、图片尺寸、视频分辨率、数量、时长、音频、
   水印和重试策略。
9. **成本边界与确认**：预计任务数、报告指纹、图片自动生产规则和唯一的视频
   确认短语。

## 确认规则

图片资产必须先生成并验收，再请求确认。确认只绑定报告指纹，并且只授权视频
生成，例如：

```text
CONFIRM PREPRODUCTION PACKAGE <report-id> <fingerprint>
```

确认只覆盖报告中列出的目标视频。任何创意或技术参数变化，或任何图片验收失败，
都必须建立新的报告状态并重新确认。

## 复用规则

资产检索必须在报告定稿前完成。已保存且在身份、风格和所需视角上匹配的成功资产
应直接复用，不得把复用资产列为新的生成目标。
