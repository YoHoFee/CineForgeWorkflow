# 视频提示词交接契约

本契约属于 `$short-video-workflow` 编排层，不修改或复制第三方
`$short-drama-video-prompts` Skill。第三方 Skill 负责创作
`视频提示词.md`；本工作流负责提供输入、接收输出、校验交接结果，并阻止不完整的
提示词进入视频确认和生产。

## 责任边界

- `$short-drama-storyboard`：决定镜头边界、起始状态、唯一动作、终点状态和连续性。
- `$short-drama-video-prompts`：把已确认分镜和视觉事实写成可复制的视频提示词。
- `$short-video-workflow`：组织调用、保存来源和哈希、校验格式及参考图语义、管理
  阻塞状态。
- `$short-drama-produce`：只在视频确认通过后实际提交视频任务。

本工作流不得把校验器变成第二个提示词作者。校验失败时，优先带着错误清单回交
`$short-drama-video-prompts` 修订；修订仍不合格时，状态保持 `blocked`，不得由
编排层默写替代正文。

## 何时调用

- `executionScope=end_to_end`：分镜和关键帧确认后，必须调用一次。
- `executionScope=stage_only`：只有用户明确要求“先做视频提示词”或当前阶段已经
  到达视频提示词时才调用；“先做剧情/角色/场景”不得提前调用。
- 用户提供了已有 `视频提示词.md`：仍需按本契约校验，不因文件存在而视为有效。
- 用户明确更换模型、时长、参考图或生成方式：重新调用并使旧交接失效。

## 交接输入

调用前必须向第三方 Skill 提供或让它读取：

1. 当前分镜和冻结关键帧。
2. 视觉设定及连续性锁。
3. 当前目标模型能力档案、原生时长和提示词语言。
4. 每镜真实参考图清单及其项目相对路径。
5. 本轮用户明确提出的动作、表演、声音或输出要求。

不能用 Canvas 节点数量、图片文件名相似或资产标题推断参考图用途。每张图必须
经过逐镜核对。

## 每镜最低结构

第三方 Skill 的输出必须保持其原生文件格式，但每镜至少可解析出以下结构：

```markdown
## MOTION-001 · 镜头名称

- 分镜：
- 时长：
- 生成方式：图生视频
- 输入参考图：
  - REF-01（顺序：1）· <项目相对路径>《<中文名称》（用途：身份；控制：<范围>；不得控制：<范围>）
  - REF-02（顺序：2）· <项目相对路径>《<中文名称>》（用途：地理；控制：<范围>；不得控制：<范围>）
  - REF-03（顺序：3）· <项目相对路径>《<中文名称>》（用途：起始帧；控制：<范围>；不得控制：<范围>）
- 静态视觉锚点：
- 起始帧：
- 状态链：
- 终点：

### 可复制提示词

> 静态视觉锚点……
>
> 起始状态……
>
> 唯一主要动作……
>
> 运镜、声音和终点……
```

上例只展示结构，不能把示例内容当作实际镜头事实。

## 参考图语义

每个真实 `REF-...` 槽位必须同时具备：

- `顺序`：在本镜请求中实际挂载的顺序。
- 项目相对路径：能从当前项目根目录解析。
- 中文名称：与项目资产登记一致。
- `用途`：只能使用 `身份`、`造型状态`、`地理`、`构图`、`尺度`、`效果`、
  `起始帧`、`结束帧`、`风格` 之一。
- `控制`：该图片在本镜中必须保持的可见事实。
- `不得控制`：该图片不能决定的动作、运镜、声音或其他事实。

常见绑定建议：

| 图片 | 用途 | 通常控制 | 通常不得控制 |
| --- | --- | --- | --- |
| 角色设定图 | `身份` 或 `造型状态` | 脸部、发型、服装、道具形制 | 后续动作、运镜、场景 |
| 场景设定图 | `地理` | 空间结构、材质、光线、环境关系 | 人物外观、表演动作 |
| 首帧图 | `起始帧` 或 `构图` | 初始站位、姿态、镜头距离、画面构图 | 后续动作、终点状态 |
| 结束帧图 | `结束帧` | 目标终点姿态和构图 | 起始动作、声音 |

只有真实文件才能写 `REF-...`。`PLAN-...` 表示创作者将自行挂图，不能进入已确认
的视频生产批次。没有参考图时，必须明确写：

```text
输入参考图：无（创作者已明确选择文生视频）
```

普通的“无”、 “待补参考图”或伪造路径都属于阻塞状态。

## 可复制正文

正文必须从分镜的已确认起点开始，在当前镜头内完成主要变化并落到明确终点，至少
覆盖：

```text
静态视觉锚点
→ 起始状态
→ 唯一主要动作
→ 次级反应
→ 运镜
→ 声音
→ 终点状态
```

正文还必须满足：

- 时长符合目标模型能力范围。
- 动作、换手、接触、落位和道具状态不跨镜省略。
- 对白或 VO 逐字来自剧本，不在视频提示词中擅自改写。
- 默认不生成字幕、caption、对白文字叠加、标题卡、Logo 或水印。
- 不含占位符、文件系统绝对路径、流程说明和 QA 结论。
- 相邻镜头需要续接时，只能引用已经存在的真实视频和真实尾帧，不能用计划帧或
  文字描述冒充实际接力素材。

## 交接状态

只有以下条件全部满足，交接才可标记 `validated`：

1. 每个目标镜头都有 `MOTION-...`。
2. 每个镜头的参考图、用途、控制范围和不得控制范围完整。
3. 每个 `REF-...` 都能解析到真实项目文件或已登记媒体。
4. 每个镜头都有可解析的时长、起点、状态链和终点。
5. 目标模型、提示词语言、生成方式和参考方式一致。
6. 没有待补参考图、伪造路径、未解决提示词错误或未确认参数。

任一条件不满足时，交接状态必须是 `blocked`，视频确认和视频生产都必须停止。
