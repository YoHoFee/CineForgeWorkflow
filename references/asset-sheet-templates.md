# 资产设定图模板

本文件定义角色和场景资产生成时使用的版式。

## 角色设定图

**画布**：选择能容纳全部信息并符合下游使用的比例。16:9 视频参考优先使用
16:9；其他情况可以使用更大且可读的比例。具体分辨率由项目生产档案和模型能力决定，
默认目标为 2K（如果项目另有明确档位，以项目档案为准）。

一张图同时承担角色展示、正/侧/背、细节和面部参考；不得再拆成草图和三视图两张资产。
下文默认描述常规角色设定图；如果项目生产档案明确采用“身份/造型分离”版式，再启用
白脸全身视图和独立面部近景规则。

**区域**：

1. 左侧约 42%：大型全身展示视图。
2. 右侧上部：在同一基线排列正面、侧面和背面全身视图。
3. 右侧中部：头发轮廓、服装、关键道具、材质和色彩的细节标注。
4. 右侧下部或边栏独立面板：仅放两张有完整面部特征的头肩近景，一张正面、一张
   侧面。两张面部近景彼此分隔，并与所有全身视图明确分栏。

按信息可读性调整区域比例，为标签、分隔线和边距留足空间。不得为维持固定比例而让
面部特写与全身视图重叠、融合或难以辨认。

**规则**：

- 所有区域使用清晰分隔线和一致的边距。
- 模板只使用通用虚线占位轮廓，但每个视图都必须有明确标签和可区分的几何
  特征。
- 正式设定图保留同样的面板结构，并替换为一个已确定的角色身份。
- 采用“身份/造型分离”版式时，全身正/侧/背视图的脸必须是纯白空白面，不出现
  眼睛、眉毛、鼻子、嘴、皮肤纹理、表情或其他可识别面部特征；不能让视频模型从
  全身视图提取或猜测五官。
- 采用该版式时，角色的面部身份特征只在旁侧两张独立面部近景中展示：一张正面、
  一张侧面。面部近景只控制身份五官，不控制体型、服装、动作或镜头。
- 采用该版式时，生成结果未遵守“全身白脸、侧置正面/侧面特写”，先修正设定图，
  不把不合格图送入视频生产。
- 不得添加场景、额外角色、标题卡、Logo 或水印。
- 面部近景必须标注 `FACE FRONT / 面部正面`、`FACE PROFILE / 面部侧面`；
  全身视图标注 `FRONT / 正面`、`PROFILE / 侧面`、`BACK / 背面`。

**模板提示词**：

> 常规版：用于生产参考板的空白角色设定图模板，使用能容纳全部信息的可读画幅，16:9 视频优先使用 16:9；不出现真实人物和具体服装；干净的浅色中性背景；左侧为大型全身展示区，右上排列 FRONT / 正面、PROFILE / 侧面、BACK / 背面三个全身人台，右中放头发、服装、道具、材质和颜色细节，右下放正面与侧面面部近景、表情和眼部细节。使用克制的技术制图线条，不出现环境、Logo 或水印，各区清晰分隔。
>
> 身份/造型分离版：用于需要把体型与服装控制和面部身份控制严格分开的角色设定图；左侧为大型全身人形占位区，人物脸部必须是纯白空白面，不得有五官；右上排列 FRONT / 正面、PROFILE / 侧面、BACK / 背面三个全身人台，脸部全部纯白无五官；右中放头发轮廓、服装结构、关键道具、材质和颜色的独立细节框；右侧独立面部区只放两个清楚分隔的通用头肩近景占位，一个 FACE FRONT / 面部正面，一个 FACE PROFILE / 面部侧面。使用克制的灰色技术制图线条，不出现真实脸、环境、Logo 或水印，各区不得重叠。

## 场景设定图

**画布**：选择能容纳全部空间信息并符合下游使用的比例。16:9 视频参考使用
16:9；具体分辨率由项目生产档案和模型能力决定，默认目标为 2K。

**区域**：

1. 左侧 46%：带通用虚线地点轮廓的主要空间总览。
2. 右上 27%：平面或俯视关系图。
3. 右中 27%：两个相互分隔的替代角度占位区。
4. 下方 54%：地形、建筑、材质、光线和常用道具的独立细节条。

**规则**：

- 绝不显示人物或人物剪影。
- 使用清晰分隔线、区域标签、箭头以及可见的尺度/关系标尺。
- 模板可以保留通用标签；正式场景设定图应使用简短标签，或将语义说明放入
  metadata，避免生成文字出现错误。
- 不得让替代角度相互接触或视觉融合。

**模板提示词**：

> 用于生产参考板的空白场景设定图模板，横向 16:9，使用项目生产档案指定的目标尺寸；不出现人物和具体地点；干净的浅色中性背景；使用深色分隔线和充足边距。左侧 46% 为主要空间总览区，只包含通用虚线景观或建筑占位轮廓，不出现可识别地点。右上区域为带虚线几何、箭头和简单尺度标尺的俯视平面图占位区。右中区域包含两个完全分隔的虚线透视角度占位区。下方为分段细节条，包含地面或地形、建筑或大型形体、材质纹理、光线方向和常用道具尺度的独立虚线框。只添加简短通用区域标签。使用克制的单色技术制图线条；不得出现真实场景、具有身份的物体、人物、Logo 或水印。所有角度和细节区域必须清晰分隔，避免参考含义混淆。
