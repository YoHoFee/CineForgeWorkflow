# 资产设定图模板

本文件定义角色和场景资产生成时使用的版式。

## 角色设定图

**画布**：选择能容纳全部信息并符合下游使用的比例。16:9 视频参考优先使用
16:9；其他情况可以使用更大且可读的比例。具体分辨率由项目生产档案和模型能力决定，
默认目标为 2K（如果项目另有明确档位，以项目档案为准）。

一张图同时承担角色展示、正/侧/背、细节和面部参考；不得再拆成草图和三视图两张资产。

**区域**：

1. 左侧 42%：大型全身展示视图。
2. 右侧 58% 的上部区域：在同一基线排列的正面、侧面和背面三视图。
3. 右侧 58% 的中部区域：头发、服装、关键道具、材质和色彩的细节标注。
4. 右侧 58% 的下部区域：中性表情、表情变化和眼部细节的面部特写区。

右侧三个区域按高度大致各占三分之一，并为标签、分隔线和边距预留空间；这里的
“58%”是画布宽度，不是三个区域各自的宽度。

**规则**：

- 所有区域使用清晰分隔线和一致的边距。
- 模板只使用通用虚线占位轮廓，但每个视图都必须有明确标签和可区分的几何
  特征。
- 正式设定图保留同样的面板结构，并替换为一个已确定的角色身份。
- 不得添加场景、额外角色、标题卡、Logo 或水印。
- 面部细节区必须包含正面和侧面占位图。侧面必须显示鼻子、嘴唇、下巴、耳朵
  和颈部方向。使用 `FRONT / 正面`、`PROFILE / 侧面`、`BACK / 背面` 标签，
  不得只依赖虚线轮廓判断视角。

**模板提示词**：

> 用于生产参考板的空白角色设定图模板，使用能容纳全部信息的可读画幅，16:9 视频优先使用 16:9；不出现真实人物和具体服装；干净的浅色中性背景；四个清晰分隔的区域，使用细深色分隔线和充足边距。左侧 42% 为大型全身展示区，只包含通用虚线人形轮廓。右上区域包含三个对齐的通用虚线人台轮廓，并明确标注 FRONT / 正面、PROFILE / 侧面、BACK / 背面。侧面占位轮廓必须明显显示鼻子、嘴唇、下巴、耳朵和颈部方向，不得画成对称椭圆。右中区域包含头发细节、服装结构、关键道具、材质纹理和颜色样本的独立虚线标注框与圆形标注。右下区域包含一个正面和一个侧面的通用虚线头肩轮廓、三个表情槽位和一个眼部细节槽位。使用简洁的技术制图线条和克制的单色灰色；不得出现具体面孔、具体人物、环境、Logo 或水印。每个区域必须相互独立且含义明确，能够作为稳定的角色参考模板。

## 场景设定图

**画布**：选择能容纳全部空间信息并符合下游使用的比例。16:9 视频参考使用
16:9；具体分辨率由项目生产档案和模型能力决定，默认目标为 2K。

**区域**：

1. 左侧 46%：带通用虚线地点轮廓的主要空间总览。
2. 右上 27%：平面或俯视关系图。
3. 右中 27%：两个相互分隔的替代角度占位区。
4. 下方 54%：地形、建筑、材质、光线和常用道具的独立细节条。

**规则**：

- 绝不显示人物或人物剪影。
- 使用清晰分隔线、区域标签、箭头以及可见的尺度/关系标尺。
- 模板可以保留通用标签；正式场景设定图应使用简短标签，或将语义说明放入
  metadata，避免生成文字出现错误。
- 不得让替代角度相互接触或视觉融合。

**模板提示词**：

> 用于生产参考板的空白场景设定图模板，横向 16:9，使用项目生产档案指定的目标尺寸；不出现人物和具体地点；干净的浅色中性背景；使用深色分隔线和充足边距。左侧 46% 为主要空间总览区，只包含通用虚线景观或建筑占位轮廓，不出现可识别地点。右上区域为带虚线几何、箭头和简单尺度标尺的俯视平面图占位区。右中区域包含两个完全分隔的虚线透视角度占位区。下方为分段细节条，包含地面或地形、建筑或大型形体、材质纹理、光线方向和常用道具尺度的独立虚线框。只添加简短通用区域标签。使用克制的单色技术制图线条；不得出现真实场景、具有身份的物体、人物、Logo 或水印。所有角度和细节区域必须清晰分隔，避免参考含义混淆。
