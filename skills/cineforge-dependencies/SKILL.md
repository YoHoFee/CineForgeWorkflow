# 影铸依赖安装

本 Skill 负责把影铸工作流依赖安装好并引导首次使用。源文件以影铸仓库为准，依赖清单
与安装源统一维护在 [依赖清单](references/dependencies.json)，执行细节见
[安装与恢复](references/install-guide.md)。不创作项目内容，不操作视频批次，不生成媒体。

## 触发与范围

- 用户主体要求“安装依赖”“装好影铸依赖”“首次安装影铸需要哪些插件/Skill”，立即执行。
- 影铸准备调用 owner 时，确认必需 Skill 不存在；或发现所需插件确实未安装/被禁用，
  自动进入恢复，只补当前缺口。安装授权来自用户的依赖安装请求，或已授权任务的必要前置。
- 普通生产不调用本 Skill，不全量扫描、不定期检查、不升级已安装依赖。
- 工具未加载时先发现工具；Canvas 未连接时交给原连接流程；渠道/账号未配置时交给对应
  设置流程。它们不是“插件未安装”，不能通过反复安装处理。
- `$infinite-canvas-bridge` 是可选协同层，缺少它时使用 Infinite Canvas 插件，不列为阻断。
- 插件被禁用时核对本轮授权；存在明确的禁用要求时保持禁用，只有用户本轮要求安装/
  恢复该插件才尝试重新启用，不把一般制作请求当作撤销禁用意图。

## 执行

1. 先说明“我会检查影铸依赖并自动补齐缺失项”，保留用户原任务和已经完成的阶段。
   不要求用户自己找仓库、复制 token、寻找目录或逐个手动安装。
2. 核对当前 Agent 可发现的 Skill、工具和本机安装。使用本 Skill 自带脚本读取实际安装，
   不以目录名、插件缓存或一次工具报错认定成功/缺失：

   ```powershell
   node <this-skill-root>/scripts/dependencies.mjs inspect
   ```

   首次安装默认补齐 11 个 Drama Skills 和 Infinite Canvas。ChatCut 是剪辑交付阶段依赖，
   用户要求全套、剪辑或交付成片时加 `--with-editing`。缺失依赖恢复用
   `--only=<skill-name-or-plugin-id>`，支持逗号分隔，只补本次确实需要的项。
   只有本次要在本机处理媒体时加 `--with-local-media` 补齐 ffmpeg/ffprobe；云端剪辑不要求它们。
3. 展示一张简短清单：依赖、用途、必需/按阶段/可选、本机状态、本轮动作。已有且可读的
   Skill 复用，已安装且启用的插件复用；可选项不为了凑齐清单强装。
4. Node/Git/Codex/Python 等运行时缺失时，先按安装指引找到宿主捆绑运行时或自动补齐
   当前必需的官方运行时，再执行脚本。运行时安装也由 Agent 完成；不把报错原样扔给用户。
5. 用户要求安装依赖时直接执行，无需再问“是否安装”；恢复分支只安装当前任务必要缺口：

   ```powershell
   node <this-skill-root>/scripts/dependencies.mjs install
   # 需要剪辑依赖
   node <this-skill-root>/scripts/dependencies.mjs install --with-editing
   # 执行中只缺 Canvas 插件
   node <this-skill-root>/scripts/dependencies.mjs install --only=infinite-canvas@infinite-canvas-local
   ```

   脚本从固定来源下载缺失的 Drama Skills；通过 Codex 官方 CLI 注册 marketplace 并安装
   `infinite-canvas@infinite-canvas-local`。安装是实际写入并复核，不用推荐卡或缓存文件冒充。
   优先使用脚本；需要改用宿主提供的直接安装工具时，仍使用清单中的确切来源/ID并复核。
6. 每项安装后复读本机状态。独立处理失败项，不因一个可选插件失败放弃已能完成的安装。
   已存在但损坏的用户级 Skill 先备份再修复；已有有效依赖不覆盖、不升级。对于项目覆盖、
   禁用项、权限策略或来源冲突，按指引处理，不绕过用户/管理员的限制。
7. 分别报告“已安装”“已启用”“当前会话已加载”“需要登录/配置”，不能把它们混为一谈。
   新安装不能在当前会话发现时提示开启新的 Agent，并给出能直接复制的下一句，例如：
   `继续刚才的影铸任务，先核验依赖已加载，再从原阶段恢复。` 不自动新建聊天。

## 首次使用引导

安装完成后只给下一步所需的说明：哪些项已补齐、哪些按阶段安装、是否需要新 Agent。
需要使用 Canvas 时给实际入口 `https://canvas.best`，后续由影铸自动连接；首次生产渠道
尚未配置时，Agent 打开该 origin 的配置页并说明需要选择的渠道/模型。登录、用户凭据
填写或平台明确要求的交互由用户完成；不索取/保存密钥，不把配置过程说成安装失败。
ChatCut 需要账号连接时打开正式连接入口并解释下一步，账号完成后复核，不要求用户
重新执行一串命令。

安装依赖不会扩大媒体生产授权，不触发图片、视频、配音、音乐生成，也不消费旧确认。
网络或安装失败时先执行指引中的自动恢复，再给具体原因、已完成项及剩余唯一动作；
不得虚构成功、随意换仓库，或为解决工具缺失写入第二份 MCP 配置。
